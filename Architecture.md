## 🎯 System Overview

The RAG-POC is a **Retrieval Augmented Generation** system that enables intelligent document Q&A by combining:

- **Document Processing**: Ingestion, chunking, and embedding of documents
- **Vector Search**: Semantic similarity search using Qdrant
- **AI Generation**: Context-aware responses using NVIDIA NIM LLMs
- **Real-time Streaming**: Server-Sent Events for live response streaming
